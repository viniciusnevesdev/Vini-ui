# Icons

Nenhum SVG foi aprovado ou incluído nesta revisão.

Nomes iniciais candidatos: add.svg, close.svg, check.svg, delete.svg, edit.svg, back.svg, forward.svg, more.svg, undo.svg e redo.svg. São nomes de referência, não uma lista de assets disponíveis.

Para cada ícone incluído, registre nome, significado, origem, licença ou permissão de uso e exceções. Mais de uma variante precisa de uma diferença explícita no nome.

SVGs monocromáticos devem herdar currentColor no fill ou stroke apropriado e manter viewBox. O componente consumidor define a dimensão com tokens aprovados. Ícones decorativos ficam ocultos para tecnologias assistivas; botões somente com ícone precisam de nome acessível no botão.
